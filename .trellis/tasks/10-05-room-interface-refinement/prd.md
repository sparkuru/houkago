# 房间界面整理

## Goal

承接已完成的首页整理，按共享视觉与体验 spec 整理部室界面，使观看内容、队列和交流的主次清晰，桌面与手机体验一致。品质按 Awwwards/Webby/FWA 参照与八维自检执行，不宣称获奖或官方认证。

## Background and Authorization

- 原始请求：`接下来，房间界面；也按照 spec 要求，整理一下`。
- 2026-10-05 用户批准 `建 task`，随后在最终方案摘要后批准 `开始实现`；本方案进入执行，提交/归档与外部发布尚未授权。

- 规划源码锚点见 `research/room-review.md`；实现、浏览器基线、迭代及最终工程证据见 `validation.md`，独立复核见 `check-review.md`。

- 2026-10-05 最终可运行结果与检查完成后，用户以 `可以提交` 接受本轮结果并授权提交与正常任务收尾；此前待验收/提交边界由此解除，push 与生产部署仍未授权。

## Requirements

### R1 — 观看优先的视觉层级

沿用 Warm Club 暖纸、墨色、木色操作与青绿焦点。压紧顶部辅助信息，保留部室名称、连接状态和唯一主观看区。节目标题、当前状态与管理动作建立清晰主次，去掉无信息增量的重复提示；空播放器以原创投影图形、简洁状态与一条有效提示表达等待。空舞台在桌面和手机均保持 16:9。

### R2 — 队列与视频来源

番组表先呈现节目列表和当前节目状态，再呈现下部统一视频来源入口。URL、可选标题、解析预览与加入队列形成一条清晰路径，保留 Baidu 功能。操作按选择、排序、单项删除、批量清空分组，危险操作与主要操作有视觉区分；长标题与手机动作区能换行。

### R3 — 交流与辅助操作

保留出席 → 弹幕来源/设置 → 聊天顺序、一个共享输入框和 `弹幕` → `发送` 两个动作。统一侧栏标题、人数/角色、说明与控件密度，减少多层卡片重复强调。固定 dock 的聊天填满剩余高度，展开设置后输入仍可达。保留既有 `+` 菜单、信息/房主管理弹窗、复制链接与返回楼层路径，以及拖动位置、焦点、inert 和 fullscreen 行为。

### R4 — 状态与文案一致性

顶部和入室门禁按真实 connecting/open/closed/error 分别显示连接中、正常、断开、异常，不把断连与错误显示为连接中，不向用户显示原始英文枚举。保留恢复、等待批准、关闭、拒绝、重连与服务端错误各自状态及已有恢复路径。新增/修改界面词汇使用现有字典；保留输入可访问名称、pending、失败和成功反馈，避免装饰动画掩盖真实状态。

### R5 — 已有删除权限契约对齐

当前前端单项删除仍采用 host-only，与 2026-10-04 已确认并写入共享 spec 的规则相冲突。对齐 UI 与前端 runtime：已入室且连接正常的房主或具番组表权限成员可删除非当前节目，不按节目添加者限制；当前节目的 UI 保护与原有确认继续保留。无权限、断连、等待入室或忙碌时不得发命令。排序与清空仍由房主执行，不修改后端规则。

### R6 — 八维与响应式完成条件

逐项检查排版、留白、视觉层级、色彩、动效、微交互、响应式、原创性，修正范围内所有可具体指出的问题，最后一次改动后重新整体检查。适用交互全部为 mobile-required。保留 room contract 的布局断点、16px dock 间隙、安全区、cinema 与 fullscreen 区别，不新增品牌配色、远程字体、外部素材或依赖。

### R7 — 全视口拖动

`+` 的拖动与方向键范围覆盖整个当前视口，包括出席标题、聊天室输入框及发送按钮所在区域。只保留 safe-area、16px 边缘间隔；取消具体内容的自动避让，允许用户所选位置覆盖底层文字/控件，拖动结束、滚动或内容变化不得自动推开。保留拖动不触发点击、位置存储、resize/cinema/fullscreen 和菜单可达；聊天室本身不变为可拖面板。

### R8 — 可扩展的来源选择

番组表仍先节目、后来源。视频来源用一个有可访问名称的原生选择器和一个可见操作面板，按既有操作方式提供“视频链接”（Bilibili/MP4/HLS/DASH）及“百度网盘”，避免来源数量增加时全量堆叠表单或横向标签。来源描述列表与对应面板保持清晰扩展点，不引入插件框架或虚构 provider。切换保留链接草稿/已解析预览与百度连接/浏览状态；隐藏面板不参与布局或键盘焦点。保留解析→预览→加入、WS 队列权威、Baidu 个人连接与 playlist 权限分工、未配置/移动端限制反馈。无 playlist 权限成员仍可进入百度个人连接流程，不能添加来源。

## Out of Scope

首页重设计、品牌重做、框架迁移、协议/数据库/后端权限改造、播放器同步算法或 provider 能力新增、真实上游/实体设备重新验收、依赖升级、preview 基础设施改造、push/生产部署。提交与正常归档已由最新用户授权纳入收尾。

## Risks and Evidence Boundary

删除权限是既有 spec 对齐，不能仅改按钮或删除旧测试而缺少负向与双客户端证据。CSS 改动可能影响 fixed dock、launcher 坐标、长文字与 cinema，必须在最终源码上重跑行为及几何验收。截图仅诊断，获奖级品质仍需主观视觉评审；模拟手机不证明真实软键盘、Safari 或上游 provider。
